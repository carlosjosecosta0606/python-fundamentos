# Curso Python Simples

Repositório criado para acompanhar meus estudos de Python, desenvolvendo os exemplos e exercícios propostos durante o curso.

## Objetivo

Este projeto tem como objetivo registrar a evolução do aprendizado da linguagem Python, desde os conceitos básicos até tópicos mais avançados.

Cada módulo do curso será versionado utilizando Git e publicado neste repositório.

## Conteúdo estudado

### Módulo 1 - Introdução

Neste módulo foram abordados os seguintes conceitos:

- Configuração do ambiente de desenvolvimento
- Instalação e configuração do Python
- Utilização do Visual Studio Code
- Criação de ambiente virtual (venv)
- Git e GitHub
- Primeiro programa em Python
- Variáveis
- Tipos básicos de dados
- Comando `print()`

## Como executar

1. Clone o repositório

```bash
git clone https://github.com/carlosjosecosta0606/CursoPythonSimples.git
```

2. Acesse a pasta

```bash
cd CursoPythonSimples
```

3. Ative o ambiente virtual

### macOS / Linux

```bash
source .venv/bin/activate
```

### Windows

```bash
.venv\Scripts\activate
```

4. Execute um dos exemplos

```bash
python exemplo.py
```
